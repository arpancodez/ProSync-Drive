# ProSync-Drive
A modern professional cloud drive platform with advanced sync, real-time file management, secure sharing, user dashboard, and robust backend features.


## Installation

```bash
git clone https://github.com/arpancodez/ProSync-Drive.git
cd ProSync-Drive

# Install dependencies
npm install

# Start the development server
npm start
```

## Features

- Real-time file synchronization
- Secure file sharing with encryption
- User-friendly dashboard
- Robust backend infrastructure
- Advanced file management

## Technologies Used

- Frontend: React, Node.js
- Backend: Express.js
- Database: MongoDB
- Deployment: Docker
